# Personal Portfolio Website

Personal portfolio website built to showcase my profile, selected projects, tech stack, and contact links.

Live site: https://radiityy-porto.vercel.app/

## Tech Stack

* Next.js
* Tailwind CSS
* Framer Motion
* React Icons
* Vercel

## Features

* Responsive portfolio layout
* Profile and short introduction
* Selected projects section
* Tech stack section
* Contact links
* Smooth animations
